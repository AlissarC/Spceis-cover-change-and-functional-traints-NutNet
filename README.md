# NutNet species cover change and functional traits Data Repository

This repository contains data and R scripts for the analysis of the relationships between species cover change and plant functional traits across 94 grassland site from NutNet.

The data and analyses in this repository are associated with the manuscript:

Eco-evolutionary optimality predicts which plant strategies succeed across global grasslands  
Cheaib et al (2026), submitted to *Nature Ecology and Evolution*.

## Repository contents

This repository contains the data used for the results presented in the manuscript (data folder), associated metadata describing the variables included in each file in the data (Metadata file), and the R scripts used to process and analyze the data and generate the figures and tables.

### `data/`

The `data` folder contains the data used in the analyses, including:

- Traits (All_traits_merged file)
- Climate and sites (climate and sites_coord files)
- Species cover data (full-cover_2025-01-31_v2 file)
- Leaf carbo isotopes (New_data_isotopes, NutNet_Firn, and Trait_Try_2025 files)
- Metadata file: each sheet containf the metadata of each file cited in the data folder)

### `scripts/`

The `scripts` folder contains the R scripts used for data processing, statistical analyses, and generation of figures and tables presented in the manuscript.

Main scripts include:

- `scripts/trait_processing_2026.R` — data processing and calculation of species cover change/relative dominance change, traits and climate merging, cleaning
- `scripts/Nmass.R` — statistical analyses/figures/tables for Nmass-species cover and relative dominance change
- `scripts/chi_all.R` — statistical analyses/figures/tables for chi-species cover and relative dominance change
- `scripts/SLA.R` — statistical analyses/figures/tables for SLA-species cover and relative dominance change
- `scripts/LDMC.R` — statistical analyses/figures/tables for LDMC-species cover and relative dominance change
- `scripts/SRL.R` — statistical analyses/figures/tables for SRL-species cover and relative dominance change
- `scripts/Hmax.R` — statistical analyses/figures/tables for Hmax-species cover and relative dominance change
- `scripts/Fig_Export.R` — figures for the main text
 `scripts/SI_Fig_tables.R` — figures and tables for the Extended data

### `output/`
The `output` folder contains the data final data used in the analysis generated by trait_processing_2026 script

### `Tables/`
The `Tables` folder is created to receive exported tables containing statistics 

### `Fig/`
The `Fig` folder is created to receive exported figures
